# check-setup — проверь моё окружение

Прогоняет диагностику и выдаёт отчёт таблицей. Ничего не чинит молча:
если что-то не так — честно помечает ошибку и предлагает шаг исправления.
Не устанавливай программы, не меняй настройки, не запускай вход или загрузку
модели только ради диагностики. Приватные конфиги, тексты и токены не выводи.

## 1. ОС и контекст

- macOS: `uname -s` → `Darwin`, затем `uname -m` и `sw_vers -productVersion`.
- Windows: нативные `$PSVersionTable` и `[Environment]::OSVersion.VersionString`.
- WSL, удалённый host и облако — отдельные среды: их команды не подтверждают
  готовность компьютера пользователя. Неподтверждённое — «не проверено».

Проверь фактические папку рабочего проекта, домашний каталог и область навыков.
Не спрашивай повторно уже известные настройки. Codex уже установлен;
`codex --version` проверяет только необязательный CLI, его отсутствие в приложении нормально.

## 2. Программы macOS

Проверяй команды по одной, не скрывай ошибки через `|| true`:

```bash
git --version
command -v brew
brew --version
ffmpeg -version
command -v whisper-cli
gh --version
```

Homebrew не обязателен, если программы работают без него. Python не нужен
пути macOS с whisper-cli. Проверь выбранный GGML-файл модели (обычно
`~/.local/share/whisper-cpp/ggml-small.bin`). Размер файла или `--help`
не доказывают распознавание: запуск и точность записи — отдельные результаты.
Не начинай обработку личного аудио без поручения и не скачивай модель для проверки.

## 3. Программы Windows

В нативном PowerShell:

```powershell
Get-Command git, winget, python, py, ffmpeg, gh -CommandType Application -All -ErrorAction SilentlyContinue
git --version
winget --version
python -c "import sys; print(sys.executable); print(sys.version)"
ffmpeg -version
gh --version
```

Используй фактический interpreter, если он вызывается не `python`. Проверь
голосовой venv (обычно `$env:LOCALAPPDATA\ff-starter-kit\voice-notes`), его
`Scripts\python.exe`, `-m pip show faster-whisper` и `-m pip check`.
Не обращайся к глобальному pip вместо выбранного окружения.
Свежая команда не найдена — сначала новая сессия приложения/терминала,
затем диагностика PATH. Не переписывай PATH, ExecutionPolicy и aliases.

## 4. Навыки, правила и память

Проверь целые `check-setup` и `voice-notes`, включая
`voice-notes/scripts/transcribe.py`, затем видимость навыков в текущей сессии.
Область Codex — пользовательская `.agents/skills/` или выбранная проектная
`.agents/skills/`; не путай их и не требуй дубликатов.

В **согласованном рабочем проекте** проверь наличие и применение `AGENTS.md`,
`ARCHITECTURE.md`, `docs/SESSION_STATE.md`. Не считай шаблоны из starter-kit
установленными правилами: проверь новую сессию выбранного проекта.

Если личный `docs/USER.md` используется, проверяй только наличие согласованного
пути и его исключение из Git, не печатай содержание. В Git-root `git ls-files -- docs/USER.md`
должен дать пустой успешный вывод, затем `git check-ignore -- docs/USER.md` —
подтвердить исключение. Отслеживаемый файл — ошибка защиты, отсутствие репозитория
или неизвестная граница — защита не проверена. Если личные факты не сохранялись,
отметь «не требуется»; не создавай их ради теста.

## 5. Внешние подключения

GitHub: `gh auth status` без `--show-token`. Не вызывай `gh auth token` и не
переключай рабочий аккаунт. Установка CLI и авторизация — разные результаты.
Если обнаружено plaintext-хранилище, сообщи проблему, не предлагай insecure-storage.

Figma: отдельно проверь наличие настройки/плагина, доступные инструменты,
авторизацию (`whoami`) и чтение разрешённого пользователем файла.
Без ссылки чтение файла — «не проверено». Наличие записи в config или
`mcp list` не доказывает доступ. Для проверки не создавай и не изменяй файлы.
Не выводи конфигурацию целиком: она может содержать секреты.

## Формат отчёта

Одна таблица. Статусы: **готово / ошибка / не проверено / не требуется**.
Полный набор проверяется по умолчанию; «не требуется» — только для неприменимого
шага или функции, от которой пользователь явно отказался.

| Проверка | Статус | Значение / что делать |
|---|---|---|
| ОС, host, shell | … | фактически проверенная среда |
| Git | … | версия |
| Homebrew или winget | … | версия, если использовался |
| Windows: Python и venv | … | фактически выбранный interpreter |
| Голос: ffmpeg и распознаватель | … | версии/реальный путь |
| Голос: модель / запись речи | … | наличие, запуск и точность раздельно |
| Навыки | … | целые папки и видимость раздельно |
| Правила и память проекта | … | файлы и применение в новой сессии |
| Защита личной памяти | … | без вывода личных фактов |
| GitHub | … | установка CLI / авторизация раздельно |
| Figma MCP | … | настройка / инструменты / OAuth / файл раздельно |

Невыполненное — «не проверено», а не выдуманный успех. Диагностика сама по себе
не разрешает исправления. Если starter-kit доступен, укажи нужный шаг
`codex/SETUP.md` или `environment/macos/SETUP.md`, `environment/windows/SETUP.md`.
После переноса навыка комплект может отсутствовать: не придумывай относительные ссылки.
