# VPN для Claude Code и Codex

> Этот файл читают и студент, и ИИ-ассистент. Студенту — чтобы выбрать способ,
> ИИ — чтобы помогать по шагам и не выдумывать.

## Зачем VPN и почему важен постоянный IP

Claude (Anthropic) и Codex (OpenAI) из России недоступны — без VPN они не
запустятся или не дадут войти в аккаунт.

Главное требование к VPN — **постоянный IP-адрес** в одной и той же стране.
Если адрес постоянно меняется (сегодня Германия, завтра Нидерланды, послезавтра
общий IP с тысячей других людей), сервисы видят «подозрительный» вход, и аккаунт
с оплаченной подпиской могут заблокировать. Поэтому обычные «бесплатные» и
массовые VPN с переключением серверов — плохой выбор.

Способов два:

1. **Свой сервер (рекомендуем).** IP только ваш и не меняется. Нужно арендовать
   сервер и домен — это ~5 $ в месяц и ~30 минут настройки (можно поручить ИИ).
2. **Купить VPN с фиксированным (выделенным) IP.** Проще, но дороже и зависит
   от честности продавца.

## Способ 1. Свой сервер на Hysteria2 (рекомендуем)

Hysteria2 — современный протокол VPN, быстрый и устойчивый к блокировкам.
Ставится на арендованный сервер (VPS) за рубежом.

### 1.1. Арендовать VPS

Подойдёт любой провайдер. Критерии:

- страна сервера — **не Россия** (Нидерланды, Германия, Финляндия и т.п.);
- операционная система — **Ubuntu 22.04 или 24.04**;
- есть **публичный IPv4-адрес** (обычно входит в тариф);
- 1 ГБ оперативной памяти и 1 ядро — достаточно;
- доступ **root по SSH** (логин и пароль или ключ провайдер присылает на почту).

Запишите IP-адрес сервера и пароль root — они понадобятся.

### 1.2. Домен или поддомен

Hysteria2 нужен домен, чтобы получить настоящий TLS-сертификат (с ним
соединение выглядит как обычный сайт и не требует «небезопасных» настроек).

- Купите любой недорогой домен (например, в зоне `.com`) у любого регистратора,
  **или** используйте поддомен уже имеющегося домена: `vpn.ваш-домен.com`.
- В панели DNS домена создайте **A-запись**: имя — домен или поддомен
  (например `vpn`), значение — IP-адрес сервера.
- Подождите 5–30 минут и проверьте, что запись работает (на Mac — в Терминале,
  на Windows — в PowerShell):

  ```
  nslookup vpn.ваш-домен.com
  ```

  В ответе должен быть IP вашего сервера.

### 1.3. Установить Hysteria2 на сервер

Есть два пути — выберите любой.

#### Путь А. Поручить ИИ (проще)

Возьмите файл `vpn/hysteria2-install-prompt.md` из этого пакета (бот курса
тоже присылает его по кнопке «📄 Промпт для ИИ») и отдайте его ИИ-агенту,
который умеет выполнять команды на вашем компьютере (Claude Code, Codex).
Агент подключится к серверу по SSH, всё установит, проверит и выдаст готовую
ссылку для подключения.

⚠️ **Курица и яйцо:** Claude Code и Codex из России без VPN не работают.
Варианты:

- временно включите любой VPN, который у вас есть, только на время установки;
- отдайте промпт любому другому доступному ИИ-агенту;
- или пройдите **Путь Б** вручную — ИИ-помощник в боте курса работает без VPN
  и подскажет, если что-то непонятно.

#### Путь Б. Вручную

1. Подключитесь к серверу (Mac — Терминал, Windows — PowerShell), вместо
   `IP` подставьте адрес сервера, пароль вводится вслепую — это нормально:

   ```
   ssh root@IP
   ```

2. Установите Hysteria2 официальным скриптом:

   ```
   bash <(curl -fsSL https://get.hy2.sh/)
   ```

3. Придумайте длинный пароль для VPN (или сгенерируйте: `openssl rand -hex 16`)
   и создайте конфиг. Замените `vpn.ваш-домен.com`, `ваша@почта.com`
   и `ПАРОЛЬ`:

   ```
   cat > /etc/hysteria/config.yaml <<'EOF'
   listen: :443

   acme:
     domains:
       - vpn.ваш-домен.com
     email: ваша@почта.com

   auth:
     type: password
     password: ПАРОЛЬ

   masquerade:
     type: proxy
     proxy:
       url: https://www.bing.com
       rewriteHost: true
   EOF
   ```

4. Откройте порты (если включён фаервол `ufw`) и запустите сервис:

   ```
   ufw allow 80/tcp; ufw allow 443/tcp; ufw allow 443/udp
   systemctl enable --now hysteria-server.service
   ```

5. Проверьте, что сервис работает и сертификат получен:

   ```
   systemctl status hysteria-server.service --no-pager
   journalctl --no-pager -e -u hysteria-server.service
   ```

   В логе не должно быть ошибок (`error`, `failed`). Ошибка про сертификат
   почти всегда значит, что A-запись домена ещё не указывает на сервер.

6. Соберите ссылку для подключения (подставьте пароль и домен):

   ```
   hysteria2://ПАРОЛЬ@vpn.ваш-домен.com:443/?sni=vpn.ваш-домен.com#ff-vpn
   ```

   Эту ссылку вы вставите в программу-клиент (раздел «Клиент» ниже).
   Никому её не пересылайте — это ключ от вашего VPN.

### 1.4. Для продвинутых: выходной SOCKS5-прокси

По умолчанию сайты видят IP вашего сервера. Если хотите, чтобы они видели
другой постоянный IP (например, купленный статический резидентный прокси),
пустите весь исходящий трафик сервера через SOCKS5. Добавьте в
`/etc/hysteria/config.yaml`:

```
outbounds:
  - name: exit
    type: socks5
    socks5:
      addr: адрес-прокси:порт
      username: логин
      password: пароль
```

Hysteria2 отправляет весь трафик через **первый** выход в списке, поэтому
ничего больше добавлять не нужно. Перезапустите сервис:

```
systemctl restart hysteria-server.service
```

Клиент на компьютере менять не нужно. После перезапуска проверка IP
(раздел «Проверка») должна показать адрес прокси, а не сервера.

⚠️ Hysteria2 работает по UDP. Если провайдер (часто мобильный интернет или
офисная сеть) режет UDP и клиент не подключается — спросите ИИ-помощника:
обычно помогает сменить порт или добавить обфускацию `salamander`.

## Способ 2. Купить VPN с фиксированным IP

Подходит, если не хотите возиться с сервером. Что проверить перед покупкой:

- в описании тарифа прямо сказано **«выделенный IP»**, «персональный IP»
  или «dedicated IP» — то есть адрес только ваш и не меняется;
- протокол **VLESS (Reality)** или **Hysteria2** — их понимает v2rayN;
- сервер **не в России**;
- продавец выдаёт **ссылку или ключ** (`vless://…` или `hysteria2://…`)
  для импорта в клиент.

Если сервис даёт подписку с десятком серверов «на выбор» — это не
фиксированный IP. Пользуйтесь одним сервером и не переключайтесь.

## Клиент на компьютере

**Если у вас уже есть работающий клиент**, который поддерживает Hysteria2
(или протокол вашего купленного VPN), — оставайтесь на нём. Главное:
включите в нём режим TUN / «системный VPN» и раздельную маршрутизацию для
России, если она есть, и пройдите проверку IP ниже.

Если клиента ещё нет — для новичков рекомендуем **v2rayN** (бесплатный,
есть для Windows, macOS и Linux).

### Установка v2rayN

1. Откройте страницу релизов: https://github.com/2dust/v2rayN/releases
   и скачайте файл из последнего релиза:
   - **Mac с процессором Apple (M1/M2/M3/M4)** — `v2rayN-macos-arm64.dmg`;
   - **Mac с процессором Intel** — `v2rayN-macos-64.dmg`;
   - **Windows** — архив `v2rayN-windows-64.zip` (распакуйте в удобную папку,
     например `C:\v2rayN`, и запускайте `v2rayN.exe`).
2. Mac: откройте `.dmg`, перетащите v2rayN в «Программы». Если macOS не даёт
   открыть («разработчик не проверен») — «Системные настройки → Конфиденциальность
   и безопасность → Всё равно открыть».
3. Язык интерфейса: «Settings» → «Language» → «Русский» (если не включился сам).

### Подключение

1. Скопируйте свою ссылку (`hysteria2://…` или `vless://…`).
2. В v2rayN: меню **«Серверы» → «Импорт ссылок общего доступа из буфера обмена»**
   (или Ctrl+V / Cmd+V в окне со списком серверов).
3. Выберите появившийся сервер и сделайте его активным (Enter или двойной клик).
4. **Только зарубежный трафик через VPN:** меню **«Настройки» → «Настройка
   региональных пресетов» → «Россия»**. Тогда российские сайты и банки
   открываются напрямую, а Claude, OpenAI, Figma — через VPN.
5. **Включите TUN:** переключатель **«Включить TUN»** внизу главного окна.
   Без TUN через VPN идёт только браузер, а Claude Code и Codex в терминале — нет.
   - Windows: v2rayN для TUN нужно запускать **от имени администратора**
     (правый клик по `v2rayN.exe` → «Запуск от имени администратора»).
   - Mac: при включении TUN система попросит пароль от компьютера — введите.

## Проверка: IP постоянный и не российский

Выполните несколько раз (сейчас, через час, завтра) в Терминале (Mac) или
PowerShell (Windows):

```
curl ipinfo.io
```

Что должно быть:

- `"ip"` — **каждый раз один и тот же** адрес;
- `"country"` — **не `RU`**.

Если адрес каждый раз разный или страна `RU` — VPN настроен неверно
(чаще всего не включён TUN). Не входите в Claude/ChatGPT, пока проверка
не проходит.

## Правила, чтобы не потерять аккаунт

- Входите в Claude и ChatGPT **только с включённым VPN** и всегда из одной
  и той же страны.
- Не переключайтесь между разными VPN и серверами «потому что этот быстрее».
- Не делитесь ссылкой на свой VPN с другими людьми: много аккаунтов с одного
  IP — тоже повод для блокировки.
