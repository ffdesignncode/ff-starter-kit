# VPN для Claude Code и Codex

> Этот файл читают и студент, и ИИ-ассистент. Студенту — чтобы выбрать способ,
> ИИ — чтобы помогать по шагам и не выдумывать.

## Зачем VPN и почему важен постоянный IP

Claude (Anthropic) и Codex (OpenAI) из России недоступны — без VPN они не
запустятся или не дадут войти в аккаунт.

Главное требование к VPN — **постоянный IP-адрес** в одной и той же стране.
Если адрес постоянно меняется (сегодня Германия, завтра Нидерланды, послезавтра
общий IP с тысячей других людей), сервисы видят «подозрительный» вход, и аккаунт
с оплаченной подпиской могут заблокировать. Поэтому обычные «бесплатные» и
массовые VPN с переключением серверов — плохой выбор.

Способов два:

1. **Свой сервер (рекомендуем).** IP только ваш и не меняется. Арендуем сервер
   и домен в Timeweb Cloud, саму установку можно поручить ИИ.
2. **Купить VPN с фиксированным (выделенным) IP.** Проще, но дороже и зависит
   от честности продавца.

## Способ 1. Свой сервер на Hysteria2 (рекомендуем)

**Сервер** — это компьютер за границей, который работает круглосуточно. Через
него пойдёт ваш интернет. **Hysteria2** — программа-VPN, которую мы поставим на
этот сервер: она быстрая и хорошо прячется от блокировок.

Порядок: арендовать сервер → купить домен → (рекомендуем) купить выходной
прокси → установить Hysteria2 (проще всего — поручить ИИ).

### 1.1. Арендовать сервер

Рекомендуем **Timeweb Cloud**: можно платить российской картой, домен
покупается там же.

1. Зарегистрируйтесь по ссылке https://timeweb.cloud/?i=17793 и пополните
   баланс на месяц аренды (цена видна при заказе).
2. В панели откройте **«Облачные серверы» → «Создать»**.
3. Система: **Ubuntu 24.04**.
4. Регион: **Амстердам (Нидерланды)** или **Франкфурт (Германия)**. Только не Россия.
5. Тариф: самый недорогой — 1 ядро и 1 ГБ памяти хватит.
6. Сеть: оставьте **публичный IPv4** — без него VPN не заработает.
7. Нажмите **«Заказать»** и подождите несколько минут.

Когда сервер запустится, откройте его вкладку **«Дашборд»**: там IP-адрес
(цифры вида `185.12.34.56`) и пароль root. Скопируйте оба в Заметки — они
понадобятся дальше.

> Другой провайдер тоже подойдёт, если: сервер не в России, Ubuntu 22.04/24.04,
> есть публичный IPv4, доступ root по SSH.

### 1.2. Домен

**Домен** — адрес вида `vpn.ваш-домен.com`. Он нужен, чтобы сервер получил
сертификат безопасности (как замочек у сайтов).

1. В панели Timeweb Cloud откройте **«Домены и SSL»** и зарегистрируйте любой
   недорогой домен, например в зоне `.com`. Уже есть домен в Timeweb Cloud —
   можно взять его.
2. Откройте свой домен → вкладка **«Поддомены» → «Добавить»**. Имя — `vpn`,
   сервер — выберите свой из списка (или впишите его IP).

   Так появится **A-запись** — строчка, которая говорит интернету:
   «`vpn.ваш-домен.com` — это IP моего сервера».

3. Через 15–60 минут проверьте. На **своём компьютере** откройте Терминал (Mac)
   или PowerShell (Windows) и введите, подставив свой домен:

   ```
   nslookup vpn.ваш-домен.com
   ```

   В ответе должен быть IP вашего сервера. Если его нет — подождите ещё, иногда
   это занимает несколько часов.

> Домен у другого регистратора: A-запись (имя `vpn`, значение — IP сервера)
> создаётся в его панели, в разделе DNS.

### 1.3. Выходной прокси — опционально, но мы рекомендуем

Шаг можно пропустить, но лучше сделать.

**Зачем.** Без прокси сайты видят адрес вашего сервера — адрес дата-центра.
С прокси они видят адрес обычного интернет-провайдера:

- ИИ-сервисы (Anthropic, OpenAI) спокойнее относятся к такому входу;
- VPN дольше живёт без блокировок — адрес сервера меньше «светится».

**Что сделать.**

1. Купите прокси здесь: https://marsproxies.com/r/136153 — тип **ISP**
   (адрес не меняется).
2. В личном кабинете найдите данные прокси для **SOCKS5**: адрес, порт, логин
   и пароль. Скопируйте их в Заметки.
3. Купить мало — прокси нужно **подключить к серверу**:
   - ставите через ИИ (1.4, путь А) — он сам спросит данные прокси;
   - ставите вручную (1.4, путь Б) — команда есть в шаге 5;
   - VPN уже работает — напишите Claude Code или Codex: «подключи выходной
     SOCKS5-прокси к моему серверу Hysteria2 по VPN.md, раздел 1.3» и дайте
     данные прокси.

Как это устроено (для ИИ и любопытных): в конец `/etc/hysteria/config.yaml`
добавляется блок, и Hysteria2 отправляет весь трафик через **первый** выход
в списке — больше ничего настраивать не нужно. Затем
`systemctl restart hysteria-server.service`. Клиент на компьютере не меняется,
проверка IP (раздел «Проверка») покажет адрес прокси.

```
outbounds:
  - name: exit
    type: socks5
    socks5:
      addr: адрес-прокси:порт
      username: логин
      password: пароль
```

### 1.4. Установить Hysteria2 на сервер

#### Путь А. Поручить ИИ (проще)

1. Возьмите файл `vpn/hysteria2-install-prompt.md` из этого пакета (бот курса
   тоже присылает его по кнопке «📄 Промпт для ИИ»).
2. Если у вас уже установлен **Claude Code или Codex** — откройте его, приложите
   файл и напишите «выполни задание из файла». ИИ спросит IP сервера, домен,
   почту и данные прокси, сам подключится к серверу, всё установит и проверит.
   Пароль root в чат не пишите — ИИ подскажет, куда его ввести.
3. В конце ИИ выдаст ссылку вида `hysteria2://…` — **сохраните её в Заметки**.
   Это ключ от вашего VPN.

⚠️ Claude Code и Codex ещё не установлены? Без VPN из России они не работают.
Тогда включите любой временный VPN на время установки — или пройдите путь Б
(ИИ-помощник в боте курса работает без VPN и подскажет, если что-то непонятно).

#### Путь Б. Вручную

**Подключение к серверу.** На своём компьютере откройте Терминал (Mac) или
PowerShell (Windows).

1. Введите команду, заменив `IP` на адрес своего сервера из «Дашборда»:

   ```
   ssh root@IP
   ```

   Например, если адрес `185.12.34.56`, команда будет `ssh root@185.12.34.56`.
   На вопрос «Are you sure you want to continue connecting» напишите `yes`
   и нажмите Enter. Затем вставьте пароль root и нажмите Enter — при вводе
   пароль не виден, это нормально.

   Получилось, если строка ввода начинается с `root@`. Теперь это окно — ваш
   сервер: **все команды ниже вставляйте сюда**, по одному блоку, после
   каждого — Enter.

**Установка и настройка.**

2. Установите Hysteria2:

   ```
   bash <(curl -fsSL https://get.hy2.sh/)
   ```

3. Получите два пароля: выполните команду два раза и сохраните оба ответа
   в Заметки. Первый — `ПАРОЛЬ` (вход в VPN), второй — `ОБФС` (маскировка
   трафика):

   ```
   openssl rand -hex 16
   ```

4. Создайте файл настроек. Сначала скопируйте блок в Заметки, замените там
   `vpn.ваш-домен.com`, `ваша@почта.com`, `ПАРОЛЬ` и `ОБФС` на свои — и только
   потом вставьте в окно сервера:

   ```
   cat > /etc/hysteria/config.yaml <<'EOF'
   listen: :443

   acme:
     domains:
       - vpn.ваш-домен.com
     email: ваша@почта.com

   auth:
     type: password
     password: ПАРОЛЬ

   obfs:
     type: salamander
     salamander:
       password: ОБФС
   EOF
   ```

   Блок `obfs` (обфускация **Salamander**) обязателен: он маскирует трафик
   Hysteria2 под случайный шум, и VPN заметно дольше не блокируют. Без него
   не настраивайте.

5. *(Пропустите, если не покупали прокси.)* Добавьте выходной прокси — так же
   замените данные на свои:

   ```
   cat >> /etc/hysteria/config.yaml <<'EOF'
   outbounds:
     - name: exit
       type: socks5
       socks5:
         addr: адрес-прокси:порт
         username: логин
         password: пароль
   EOF
   ```

**Запуск и ссылка.**

6. Откройте **порты** — это «двери», через которые сервер принимает
   подключения. Порт 80 нужен для получения сертификата, 443 — для самого VPN:

   ```
   ufw allow 80/tcp; ufw allow 443/tcp; ufw allow 443/udp
   ```

7. Запустите VPN:

   ```
   systemctl enable --now hysteria-server.service
   ```

8. Подождите полминуты и проверьте:

   ```
   systemctl is-active hysteria-server.service
   ```

   Должно быть `active`. Если нет — посмотрите лог и покажите его ИИ-помощнику:

   ```
   journalctl --no-pager -n 30 -u hysteria-server.service
   ```

   Ошибка про сертификат почти всегда значит, что A-запись домена ещё не
   указывает на сервер (см. 1.2).

9. Соберите свою ссылку: скопируйте строку в Заметки и замените `ПАРОЛЬ`,
   `ОБФС` и оба раза `vpn.ваш-домен.com` на свои:

   ```
   hysteria2://ПАРОЛЬ@vpn.ваш-домен.com:443/?sni=vpn.ваш-домен.com&obfs=salamander&obfs-password=ОБФС#ff-vpn
   ```

   Это ваша ссылка для подключения — сохраните её и никому не пересылайте.

⚠️ Hysteria2 работает по UDP. Если провайдер (часто мобильный интернет или
офисная сеть) режет UDP и клиент не подключается — спросите ИИ-помощника:
обычно помогает сменить порт.

## Способ 2. Купить VPN с фиксированным IP

Подходит, если не хотите возиться с сервером. Что проверить перед покупкой:

- в описании тарифа прямо сказано **«выделенный IP»**, «персональный IP»
  или «dedicated IP» — то есть адрес только ваш и не меняется;
- протокол **VLESS (Reality)** или **Hysteria2** — их понимает v2rayN;
- сервер **не в России**;
- продавец выдаёт **ссылку или ключ** (`vless://…` или `hysteria2://…`)
  для импорта в клиент — сохраните его в Заметки.

Если сервис даёт подписку с десятком серверов «на выбор» — это не
фиксированный IP. Пользуйтесь одним сервером и не переключайтесь.

## Клиент на компьютере

**VPN-клиент** — программа на вашем компьютере, которая подключается к вашему
серверу (или купленному VPN) и пускает через него интернет. Сервер — это
туннель, клиент — вход в него.

Рекомендуем бесплатный **v2rayN** (Windows, macOS, Linux) — он точно умеет всё
нужное.

**Уже есть своя VPN-программа** и хотите остаться на ней? Попробуйте добавить
в неё свою ссылку (раздел «Подключение» ниже). Если программа ссылку не приняла
или не подключается — она не поддерживает Hysteria2 с маскировкой Salamander,
ставьте v2rayN. Если подключилась — включите в ней режим TUN / «системный VPN»
и раздельную маршрутизацию для России, если она есть, и пройдите проверку IP.

### Установка v2rayN

1. Откройте страницу релизов: https://github.com/2dust/v2rayN/releases
   и скачайте файл из последнего релиза:
   - **Mac с процессором Apple (M1/M2/M3/M4)** — `v2rayN-macos-arm64.dmg`;
   - **Mac с процессором Intel** — `v2rayN-macos-64.dmg`;
   - **Windows** — архив `v2rayN-windows-64.zip` (распакуйте в удобную папку,
     например `C:\v2rayN`, и запускайте `v2rayN.exe`).
2. Mac: откройте `.dmg`, перетащите v2rayN в «Программы». Если macOS не даёт
   открыть («разработчик не проверен») — «Системные настройки → Конфиденциальность
   и безопасность → Всё равно открыть».
3. Язык интерфейса: «Settings» → «Language» → «Русский» (если не включился сам).

### Подключение

1. Скопируйте свою ссылку. Где она:
   - ставили через ИИ — ИИ выдал её в конце (строка `hysteria2://…`);
   - ставили вручную — вы собрали её в 1.4, путь Б, шаг 9;
   - купили VPN — её прислал продавец (`vless://…` или `hysteria2://…`).
2. В v2rayN: меню **«Серверы» → «Импорт ссылок общего доступа из буфера обмена»**
   (или Ctrl+V / Cmd+V в окне со списком серверов).
3. Выберите появившийся сервер и сделайте его активным (Enter или двойной клик).
4. **Только зарубежный трафик через VPN:** меню **«Настройки» → «Настройка
   региональных пресетов» → «Россия»**. Тогда российские сайты и банки
   открываются напрямую, а Claude, OpenAI, Figma — через VPN.
5. **Включите TUN:** переключатель **«Включить TUN»** внизу главного окна.
   Без TUN через VPN идёт только браузер, а Claude Code и Codex в терминале — нет.
   - Windows: v2rayN для TUN нужно запускать **от имени администратора**
     (правый клик по `v2rayN.exe` → «Запуск от имени администратора»).
   - Mac: при включении TUN система попросит пароль от компьютера — введите.

## Проверка: IP постоянный и не российский

Выполните несколько раз (сейчас, через час, завтра) в Терминале (Mac) или
PowerShell (Windows):

```
curl ipinfo.io
```

Что должно быть:

- `"ip"` — **каждый раз один и тот же** адрес;
- `"country"` — **не `RU`**.

Если адрес каждый раз разный или страна `RU` — VPN настроен неверно
(чаще всего не включён TUN). Не входите в Claude/ChatGPT, пока проверка
не проходит.

## Правила, чтобы не потерять аккаунт

- Входите в Claude и ChatGPT **только с включённым VPN** и всегда из одной
  и той же страны.
- Не переключайтесь между разными VPN и серверами «потому что этот быстрее».
- Не делитесь ссылкой на свой VPN с другими людьми: много аккаунтов с одного
  IP — тоже повод для блокировки.
