# Стартовый пакет «комплект молодого бойца»

Набор для студента, который начинает работать с **Claude Code** или **Codex** —
ИИ-ассистентами, которые умеют сами выполнять команды, править файлы и помогать
с учёбой и проектами.

Репозиторий: https://github.com/ffdesignncode/ff-starter-kit — обновить пакет
можно командой `git pull` в этой папке (или скачать свежий архив у бота курса).

Пакет делает три вещи:

1. **Настраивает окружение** — по инструкции `SETUP.md` Claude сам поставит нужные
   программы (git, ffmpeg, расшифровщик голоса и т.д.) и проверит, что всё работает.
2. **Задаёт правила работы** — файл `CLAUDE.md` (для Codex — `AGENTS.md`) учит ИИ отвечать коротко,
   не выдумывать и показывать доказательства вместо «я всё сделал».
3. **Даёт память между сессиями** — шаблоны `ARCHITECTURE.md` и
   `docs/SESSION_STATE.md`, чтобы Claude не забывал, на чём вы остановились.

> Пакет поддерживает **macOS** и **Windows** (нативно, без WSL). Инструкция
> для macOS — `SETUP.md`, для Windows — `SETUP_WINDOWS.md`.

---

## Как начать

0. **Настрой VPN** — Claude и Codex из России не работают. Как выбрать VPN
   с постоянным IP и настроить его — в файле `VPN.md`.
1. **Заведи аккаунт и оплати подписку** — Claude Pro (для Claude Code) или
   ChatGPT Plus (для Codex). Как зарегистрироваться в ChatGPT из России,
   подтвердить телефон и оплатить — в файле `SUBSCRIPTION.md`.
2. **Получи эту папку** `ff-starter-kit/` (скачай архивом или склонируй репозиторий)
   и положи её в удобное место, например `~/Projects/ff-starter-kit`
   (на Windows: `C:\Users\<ты>\Projects\ff-starter-kit`).
3. **Установи приложение** — терминал для этого не нужен:
   - **Claude**: скачай приложение Claude с https://claude.ai/download, установи,
     войди в аккаунт, открой вкладку **Code** и выбери эту папку
     (Local → Open folder).
   - **Codex**: скачай приложение ChatGPT для компьютера с
     https://chatgpt.com/download, войди, выбери режим Codex и открой эту папку.
4. **Напиши ИИ в этой папке**:
   - на macOS: `настрой меня по SETUP.md`
   - на Windows: `настрой меня по SETUP_WINDOWS.md`

   Дальше ИИ сам пойдёт по шагам: будет выполнять команды, отчитываться и задавать
   тебе вопросы только там, где нужен человек (пароль, вход в аккаунты,
   подтверждения). Когда он просит разрешение на команду — разрешай. Файлы пакета —
   это шаблоны: ИИ сам скопирует их туда, где они начнут работать.

   Если любишь терминал — вместо приложения можно поставить Claude Code командой
   (`brew install --cask claude-code` на macOS, `irm https://claude.ai/install.ps1 | iex`
   в PowerShell на Windows) и написать то же самое в `claude`.

Настройка занимает 20–40 минут, из которых большая часть — скачивание модели
распознавания речи (~0.5–1.5 ГБ).

## Что делать, если что-то пошло не так

- **Claude сообщил об ошибке и остановился** — это нормально и правильно: он не
  должен выдумывать обходы. Прочитай, что он написал, и попроси помощь.
- **Не понимаешь, что происходит** — спроси у Claude простыми словами:
  «объясни, что ты делаешь и зачем». Он обязан ответить коротко и понятно.
- **Совсем застрял** — напиши боту поддержки курса, приложив текст ошибки
  или скриншот терминала.

## Что внутри папки

| Файл | Для кого | Что это |
|---|---|---|
| `README.md` | тебе | эта инструкция |
| `SETUP.md` | Claude Code | пошаговая настройка окружения (macOS) |
| `SETUP_WINDOWS.md` | Claude Code | пошаговая настройка окружения (Windows) |
| `VPN.md` | тебе и ИИ | как выбрать и настроить VPN с постоянным IP |
| `SUBSCRIPTION.md` | тебе | аккаунт и подписка ChatGPT (Codex) из России |
| `vpn/hysteria2-install-prompt.md` | ИИ-агент | задание для ИИ: поставить свой VPN-сервер |
| `CLAUDE.md` | Claude Code | правила работы — скопируется в твой будущий проект |
| `AGENTS.md` | Codex | те же правила работы для Codex |
| `ARCHITECTURE.md` | Claude Code | шаблон «карты проекта» |
| `docs/SESSION_STATE.md` | Claude Code | шаблон памяти между сессиями |
| `settings.snippet.json` | Claude Code | кусок конфигурации `~/.claude/settings.json` |
| `hooks/` | Claude Code | автоматические напоминания для Claude |
| `output-styles/` | Claude Code | стиль коротких ответов |
| `skills/` | Claude Code | готовые навыки: проверка окружения, расшифровка голосовых |
| `scripts/transcribe.py` | Claude Code | скрипт расшифровки голоса в текст (Windows, faster-whisper) |

После настройки рабочие файлы будут жить в твоём проекте и в `~/.claude/`. Саму
папку пакета всё равно **не удаляй**: на Windows скилл voice-notes вызывает из
неё `scripts/transcribe.py` для расшифровки голосовых.
