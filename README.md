# Starter-kit для Codex

Набор для студента, который начинает работать с **Codex** — ИИ-ассистентом,
который умеет выполнять команды, править файлы и помогать с учёбой и проектами.
Codex уже установлен. Комплект подготовит программы, навыки, правила работы
и файловую память проекта на **macOS** или **нативной Windows**.

## Как начать

1. Распакуй ZIP и открой в установленном Codex папку комплекта,
   в которой лежат этот README и папки `codex`, `environment`.
   Если приложение просит войти, войди в свой аккаунт лично.
2. Напиши Codex:

   ```text
   Настрой меня полностью по codex/SETUP.md. Определи ОС, установи недостающие
   программы и навыки комплекта, сохрани существующие настройки и проверь результат.
   ```

Дальше Codex сам проверяет существующие программы, ставит недостающие и идёт
по шагам. Повторно разрешать установку каждого компонента не нужно;
действующие разрешения приложения сохраняются. Если ты явно откажешься
от функции, агент её пропустит и отметит это в результате.

Полная настройка включает **Git, голосовые заметки с моделью распознавания,
GitHub CLI, навыки check-setup и voice-notes, правила и память рабочего проекта**.
Менеджер пакетов ставится при необходимости. На Windows голосовому скрипту
нужен Python и отдельное окружение; на macOS используется whisper-cli.
Отдельные Codex CLI, Node.js, Git Bash и WSL для этого комплекта не обязательны.

Когда нужен пароль ОС, системное подтверждение или личный вход в сервис,
Codex объяснит действие. Выполни его в системном окне, браузере или своём
терминале и напиши «готово». Пароли, токены и коды в чат не отправляй.
Если действие непонятно — попроси объяснить его и последствия.

Подготовка Figma и GitHub, авторизация и доступ к файлам проверяются отдельно.
Ожидание твоего входа не мешает агенту завершить независимые шаги.
Комплект не покупает подписки и не создаёт аккаунты автоматически.
Справка о доступе и тарифе — [codex/SUBSCRIPTION.md](codex/SUBSCRIPTION.md).

Нужна локальная папка, доступная инструментам Codex: прикреплённый ZIP
в облачном чате сам по себе не даёт доступа к твоему компьютеру.
Рабочий проект создаётся отдельно от starter-kit, его место и название
согласуются с тобой. Сохраняй комплект как источник шаблонов и инструкций.

## Получить и обновить комплект

Репозиторий: [ffdesignncode/ff-starter-kit](https://github.com/ffdesignncode/ff-starter-kit).
Он публичный: для скачивания ZIP вход в GitHub не требуется.

**Без Git:** нажми **Code → Download ZIP** и распакуй архив. Открой папку
`ff-starter-kit-main`, в которой лежат `README.md`, `codex/` и `environment/`.
Если архив прислал бот, открой папку с тем же содержимым; её название может отличаться.
Git для скачивания архива не нужен.

**Clone — по желанию**, если Git уже установлен:

```text
git clone https://github.com/ffdesignncode/ff-starter-kit.git
```

Открой папку `ff-starter-kit`. Не добавляй токен в URL команды.

**Обновление ZIP:** свежий архив распакуй в новую папку рядом, не поверх старой.
Codex сравнит файлы и поможет сохранить изменения. В ZIP нет Git-истории,
`git pull` к нему не применяется.

**Обновление клона выполняет Codex:** проверь настоящий корень через
`git rev-parse --show-toplevel`, перейди туда и выполни:

```text
git remote get-url origin
git branch --show-current
git status --porcelain=v1 --untracked-files=all
```

Только для нужного клона `ffdesignncode/ff-starter-kit`, правильного `origin`,
ветки `main` и пустого последнего вывода:

```text
git pull --ff-only origin main
```

При локальных изменениях, другой ветке/remote, ошибке доступа или разошедшейся
истории остановись и сохрани данные. Не применяй `reset --hard`, `clean`,
автоматический stash или rebase. Обновление исходников не обновляет уже
установленные навыки и правила проекта: их нужно сравнить и объединить
по [инструкции настройки](codex/SETUP.md), сохранив пользовательские файлы.

## Что внутри

| Файл | Что это |
|---|---|
| [codex/SETUP.md](codex/SETUP.md) | единая инструкция, которую выполняет Codex |
| `codex/AGENTS.template.md` | шаблон правил рабочего проекта |
| `codex/ARCHITECTURE.md` | шаблон карты проекта |
| `codex/docs/SESSION_STATE.md` | шаблон памяти текущего состояния |
| [environment/macos/SETUP.md](environment/macos/SETUP.md) | программы для macOS |
| [environment/windows/SETUP.md](environment/windows/SETUP.md) | программы для Windows |
| `environment/skills/check-setup/` | диагностика без автоматических изменений |
| `environment/skills/voice-notes/` | расшифровка аудио/видео со своим скриптом |

## Если что-то пошло не так

- Codex сообщил об ошибке — попроси объяснить, что не выполнено и что нужно дальше.
- Не понимаешь действие — спроси: «объясни, что ты делаешь и зачем».
- Застрял — передай поддержке курса обезличенный текст ошибки, без секретов,
  полных конфигов и личных расшифровок.

Наличие файлов не означает готовность компьютера: в конце Codex покажет,
что проверено, что пропущено по твоей просьбе и что ждёт личного действия.

Для разработчика бота: [пути сборки ZIP и инструкций](https://github.com/ffdesignncode/ff-starter-kit/blob/main/docs/BOT_BUILD.md).
