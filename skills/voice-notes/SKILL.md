# voice-notes — расшифровка голосовых в текст

Локальная расшифровка: бесплатно, работает без интернета,
аудио никуда не отправляется.

Сначала определи ОС и работай по соответствующей ветке:

```bash
uname -s   # Darwin = macOS; MINGW*/MSYS* = Windows (Git Bash)
```

## Предпосылки (macOS)

- `whisper-cli` установлен (`brew install whisper-cpp`).
- Модель лежит в `~/.local/share/whisper-cpp/ggml-small.bin`.
  (Если пользователь ставил `ggml-large-v3-turbo.bin` — используй её.)
- `ffmpeg` установлен.

Если чего-то нет — скажи об этом и сошлись на шаги 4–5 SETUP.md.
Не выдумывай альтернативные пути к модели — проверь `ls ~/.local/share/whisper-cpp/`.

## Предпосылки (Windows)

- `python` и `ffmpeg` установлены и доступны в PATH.
- Установлен faster-whisper (`pip show faster-whisper`; если нет —
  `pip install faster-whisper`, шаг 5 SETUP_WINDOWS.md).
- Отдельная модель не нужна: faster-whisper скачивает её сам при первом запуске.

## Процесс (macOS)

1. Пользователь надиктовывает голосовое или кружок в Telegram и скачивает
   файл на компьютер (десктопный Telegram: правый клик → «Сохранить как…»).
   Обычно это `.ogg` (голосовое) или `.mp4` (кружок).
2. Конвертируй в wav 16 кГц моно (формат, который ждёт whisper):

   ```bash
   ffmpeg -i "<входной файл>" -ar 16000 -ac 1 -c:a pcm_s16le -y /tmp/voice_input.wav
   ```

3. Расшифруй:

   ```bash
   whisper-cli -m ~/.local/share/whisper-cpp/ggml-small.bin -l ru \
     -f /tmp/voice_input.wav -otxt -of /tmp/voice_out
   ```

   Текст окажется в `/tmp/voice_out.txt`.

4. Покажи расшифровку пользователю целиком (это его слова — не сокращай
   и не пересказывай без запроса). Если длинная — сохрани в файл проекта
   (например `transcripts/YYYY-MM-DD-<тема>.txt`) и покажи начало.

5. Удали временные файлы: `rm /tmp/voice_input.wav /tmp/voice_out.txt`.

## Процесс (Windows)

1. Пользователь надиктовывает голосовое или кружок в Telegram и скачивает
   файл на компьютер (десктопный Telegram: правый клик → «Сохранить как…»).
   Обычно это `.ogg` (голосовое) или `.mp4` (кружок).
2. Расшифруй скриптом пакета — он сам конвертирует через ffmpeg и прогоняет
   faster-whisper:

   ```powershell
   python <пакет>\scripts\transcribe.py "<входной файл>" -o transcript.txt
   ```

   (в Git Bash путь к скрипту через `/`, например
   `python ~/Projects/ff-starter-kit/scripts/transcribe.py voice.ogg -o transcript.txt`)

   При первом запуске модель `small` (~466 МБ) скачается автоматически —
   предупреди пользователя, что первый раз будет долго.

3. Покажи расшифровку пользователю целиком (это его слова — не сокращай
   и не пересказывай без запроса). Если длинная — сохрани в файл проекта
   (например `transcripts/YYYY-MM-DD-<тема>.txt`) и покажи начало.

## Правила

- Расшифровка = стенограмма. Не редактируй, не «улучшай», не переформулируй
  слова пользователя, если он не просил.
- Если whisper выдал пусто или мусор — честно скажи: возможно, тихая запись
  или не русская речь. Предложи проверить файл (`ffprobe`), не выдумывай текст.
- Дальнейшие действия (конспект, задачи из голосового) — только по явной
  просьбе после показа расшифровки.
