# Задание для ИИ-агента: поставить VPN-сервер Hysteria2

> Студент: скопируйте весь этот файл в Claude Code / Codex (или скажите агенту
> «выполни vpn/hysteria2-install-prompt.md»). Агент будет задавать вопросы —
> отвечайте на них. Пароль от сервера вводите сами, когда попросит терминал.

---

Ты — ИИ-агент с доступом к терминалу на компьютере студента. Задача: настроить
на арендованном сервере студента VPN-сервер **Hysteria2** с настоящим
TLS-сертификатом и выдать студенту ссылку для подключения. Студент — новичок,
объясняй коротко и без жаргона, по одному действию за раз.

## Железные правила

- **Не выдумывай.** Каждый шаг подтверждай реальным выводом команды. Если
  команда упала — покажи ошибку как есть и остановись, не придумывай обходов.
- **Пароль root не спрашивай в чате.** Если вход по паролю — студент вводит
  его сам в терминал, когда `ssh` попросит. Если у тебя нет интерактивного
  терминала — попроси студента один раз выполнить `ssh-copy-id root@IP`
  (пароль он введёт сам), дальше работай по ключу.
- Ничего не делай на сервере сверх этой инструкции. Не меняй SSH-настройки,
  не отключай root-вход, не ставь лишние пакеты.
- Пароль VPN и итоговую ссылку покажи студенту один раз в конце и предупреди:
  это ключ от его VPN, никому не пересылать.

## Шаг 1. Собери данные (спроси одним сообщением)

1. IP-адрес сервера (VPS) и логин (обычно `root`).
2. Домен или поддомен для VPN (например `vpn.example.com`), у которого уже есть
   A-запись на IP сервера. Если домена нет — остановись и объясни студенту, что
   нужно сделать по разделу 1.2 файла `VPN.md`.
3. E-mail для сертификата Let's Encrypt/ZeroSSL (любой рабочий).
4. Необязательно: выходной SOCKS5-прокси (адрес:порт, логин, пароль), если
   студент хочет, чтобы сайты видели IP прокси, а не сервера. Если прокси ещё
   нет и студент хочет его — покупать здесь: https://marsproxies.com/r/136153,
   тип ISP (статический IP).

## Шаг 2. Проверь домен

Локально:

```
nslookup ДОМЕН
```

IP в ответе должен совпасть с IP сервера. Если нет — остановись: без этого
сертификат не выпустится. Объясни студенту, что нужно подождать обновления DNS
или поправить A-запись.

## Шаг 3. Подключись к серверу и проверь систему

```
ssh root@IP
cat /etc/os-release | head -3
```

Ожидается Ubuntu или Debian. Если другая система — сообщи студенту и спроси,
продолжать ли.

## Шаг 4. Установи Hysteria2

На сервере:

```
bash <(curl -fsSL https://get.hy2.sh/)
hysteria version
```

## Шаг 5. Сгенерируй пароль и запиши конфиг

```
openssl rand -hex 16
```

Создай `/etc/hysteria/config.yaml` (подставь домен, e-mail, пароль):

```
listen: :443

acme:
  domains:
    - ДОМЕН
  email: EMAIL

auth:
  type: password
  password: ПАРОЛЬ

masquerade:
  type: proxy
  proxy:
    url: https://www.bing.com
    rewriteHost: true
```

Если студент дал SOCKS5 — добавь в конец (Hysteria2 отправляет весь трафик
через первый outbound в списке, ACL не нужен):

```
outbounds:
  - name: exit
    type: socks5
    socks5:
      addr: АДРЕС:ПОРТ
      username: ЛОГИН
      password: ПАРОЛЬ_ПРОКСИ
```

Покажи итоговый конфиг командой `cat`, **замаскировав пароли** в выводе для
студента.

## Шаг 6. Фаервол и запуск

```
command -v ufw && ufw status
```

Если `ufw` активен — открой порты:

```
ufw allow 80/tcp
ufw allow 443/tcp
ufw allow 443/udp
```

Если провайдер VPS использует внешний фаервол в панели управления — попроси
студента открыть там те же порты.

Запусти сервис:

```
systemctl enable --now hysteria-server.service
sleep 15
systemctl is-active hysteria-server.service
journalctl --no-pager -n 50 -u hysteria-server.service
```

Ожидается `active` и в логе — успешное получение сертификата, без `error`.
Если ошибка сертификата — проверь шаг 2 и порты 80/443 tcp, покажи лог студенту.

## Шаг 7. Проверь, что сервер слушает порт

```
ss -ulpn | grep 443
```

Должен быть процесс `hysteria` на UDP 443.

Если был SOCKS5 — проверь, что прокси доступен с сервера:

```
curl -s --socks5 ЛОГИН:ПАРОЛЬ_ПРОКСИ@АДРЕС:ПОРТ ipinfo.io
```

## Шаг 8. Выдай ссылку

```
hysteria2://ПАРОЛЬ@ДОМЕН:443/?sni=ДОМЕН#ff-vpn
```

Объясни студенту следующий шаг: вставить ссылку в клиент (v2rayN или любой
клиент с поддержкой Hysteria2), включить TUN и региональный пресет «Россия»,
затем проверить `curl ipinfo.io` — по разделам «Клиент» и «Проверка» файла
`VPN.md`.
